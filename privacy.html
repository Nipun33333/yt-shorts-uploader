Privacy Policy

Last updated: 1 November 2026

YT Shorts Uploader is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

Data accessed

With the owner's permission, the app uses Google's YouTube Data API with the youtube.upload scope to upload videos and set their titles, descriptions and tags. It does not read, collect, sell or share any other Google user data.

Storage

The OAuth credentials are stored only as encrypted GitHub Actions secrets in the owner's repositories. No user data is stored on any other server.

Sharing

No data is shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
